Halo Map Porter

Converts maps between the Master Chief Collection, Halo Custom Edition and the original Xbox, in any direction. It handles the fixes and limits of each game for you: stock content swaps, Xbox models, HUDs and sounds, and the Xbox's map size, tag memory and texture memory.

Halo 1 Unlimited

Halo for the original Xbox, built from OpenCE, the community's decompilation of Halo: Combat Evolved (its rebuilt source code). It feels like stock Xbox Halo, with modern netcode underneath. Up to 16 consoles can play, consoles can join games in progress, AI is synced to everyone, maps download in the lobby, and the texture cache is bigger than the retail game's.

How they fit together

1. Port a map

Halo Map Porter converts a Custom Edition or MCC map for the Xbox, sized for the Xbox's memory. It writes it as a map folder with its own picture, description and player counts.

2. Drop it in

Copy the folder to maps\ on the Xbox's hard drive. It shows up in the map browser, with sorts, favourites and play counts.

3. Play it together

Host it on system link, or over XLink Kai. Consoles that don't have the map download it from the host in the lobby, even when they join a game already under way.
