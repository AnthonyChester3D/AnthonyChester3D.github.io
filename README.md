# Project pages

The GitHub Pages site for [Halo Map Porter](https://github.com/AnthonyChester3D/halo-map-porter) and
[Halo 1 Unlimited](https://github.com/AnthonyChester3D/halo-1-unlimited). Plain HTML and CSS, no build step:
GitHub Pages serves this folder as it is.

- `index.html`: the home page
- `halo-map-porter.html`, `halo-1-unlimited.html`: one page per project
- `assets/style.css`: shared styles (dark by default, light when the system is light)
- `assets/img/`: screenshots
